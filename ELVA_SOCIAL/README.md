# ELVA Social AI

Single-page React + Vite marketing site with locally simulated product interactions. No backend, publishing integration, authentication, or analytics service is included.

## Run locally

```bash
npm install
npm run dev
```

## Included interactions

- Scroll-linked product workflow stages
- Event-to-content generation mockup
- LinkedIn / Instagram / Facebook content adaptations
- Editable, regeneratable, approvable content preview
- Calendar post detail selection
- Responsive navigation and accessible FAQ disclosures
